# Поверка дома — дизайн-лаборатория

[Опубликованный сайт](https://danil-xyz.github.io/poverkadoma-design-lab/) содержит рабочий макет, 27 серий экспериментов, исследования и EPC-сценарии.

## Сборка и проверка

Требуется Node.js 22 или новее. Зависимости vendored, установка npm не требуется; сборка не обращается к сети и не создаёт каталоги.

```powershell
node build-site.cjs
```

Команда последовательно собирает макет, проверяет его, собирает сайт, проверяет сайт и обновляет index.html, site.css, site.js, data.js, README.txt и manifest в корне. Текущие preview/data intermediates игнорируются Git; исторические HTML экспериментов являются неизменяемыми исходными снимками. Все runtime-файлы включены локально.

Для проверки публикации: `node verify-site.cjs`. Публикация — обычный fast-forward Git push в main и существующий GitHub Pages из корня; force-push запрещён. Изменения проверяются и публикуются последовательно после пересборки.

DOM QA проверяет сценарии, схемы и источники, но не заменяет проверку геометрии и взаимодействия в настоящем браузере. Интеграционный baseline переносит существующий вид без исправления D001.

## Состав

- poverkadoma-home*, request-* и verifier-* — исходники рабочего макета и QA.
- poverkadoma-design-site.* и site-build.cjs — оболочка и сборка сайта.
- Исторические HTML, JSON аудитов, правил, идей и EPC — сохранённые материалы исследования.
- poverkadoma-site-* — локальные runtime и vendored библиотеки; исходные комментарии лицензий сохранены.
- fig-*.png и home asset/expanded — изображения и иконки.

Реальные серверные операции заменены демо-сценариями. Репозиторий не содержит сырых Confluence-экспортов, средств входа или сохранённых учётных данных.
